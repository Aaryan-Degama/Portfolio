# Aaryan Degama — Portfolio

Personal portfolio site. Vite + React + TypeScript + Tailwind CSS + Framer Motion, deployed as static assets on Cloudflare Workers.

## Run locally

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`.

## Build

```bash
npm run build
```

## Preview the production build

```bash
npm run preview
```

## Deploy (Cloudflare Workers)

Requires a Cloudflare account; run `npx wrangler login` once first.

```bash
npm run deploy
```
