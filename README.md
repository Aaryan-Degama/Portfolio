# Degama Aaryan Jitendrakumar — Portfolio

A personal portfolio built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion. It presents selected projects, interactive project pages, a command palette, and visitor-selectable color themes.

## Featured projects

### [Vanta](https://github.com/Aaryan-Degama/Vanta)

Semantic search for photos and files without giving up privacy. Vanta runs on-device on Android and combines CLIP, ArcFace, BERT-tiny NER, SQLite, and sqlite-vec.

- [Download Vanta v0.1.1](https://github.com/Aaryan-Degama/Vanta/releases/tag/v0.1.1)

### [LilCV](https://github.com/Aaryan-Degama/LilCV)

A dependency-light C++ computer-vision library with ONNX Runtime inference and MiDaS-Small monocular depth estimation — without OpenCV.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run typecheck
npm run build
```
